MISSION 1
📌 変更のステージングとコミット

新機能のコード修正が完了し、`index.html` というファイルが作成・編集されました。
この変更をステージングエリアに追加し、メッセージ "Add new index page" でコミットしてください。

コミット待ちのファイル: index.html (Unstaged)
$
💡 ヒント: ステージングには git add、保存には git commit -m "..." を使います。
MISSION 2
🌿 ブランチの作成と切り替え

バグ修正用の新しいブランチ fix-bug を作成して、そのブランチへ切り替えてください。

現在のブランチ: main
$
💡 ヒント: ブランチ作成と切り替えを同時に行うコマンド（または個別コマンド）を使ってみましょう。
MISSION 3
🔀 ブランチのマージ

開発ブランチ feature での作業が完了しました。
現在あなたがいるブランチは main です。feature ブランチの変更を main に取り込んで（マージして）ください。

現在のブランチ: main
マージ対象: feature
$
💡 ヒント: 統合先（main）に移動した状態で git merge [ブランチ名] を実行します。
